# Limitations and claim boundaries

1. Stage-1 and Stage-2 have no defensible row-level temporal correspondence.
2. The system does not claim Stage-2 predicts Stage-1 outcomes.
3. Learned binary forecasting does not beat the persistence baseline.
4. No measured “minutes before compromise” lead time is available.
5. State-transition test generalisation is weak.
6. Stage-2 class support is uneven across families.
7. MITRE output is transparent behavioural evidence, not labelled-stage classification.
8. The package is an offline analyst decision-support demonstration, not validated production real-time defence.
