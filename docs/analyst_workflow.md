# Analyst workflow

1. Open the recorded replay dashboard and select a case/window.
2. Review the Stage-1 flow-channel current risk and forecast trajectory. Remember persistence is the current reference.
3. Review the independent Stage-2 family probabilities and behaviour changes when supplied.
4. Read XAI drivers and MITRE evidence as supporting context, not causality or ground truth.
5. Check uncertainty and provenance before acting.
6. Follow the displayed recommendation, retaining the separate source channels in any incident note.
