# Recorded dataset replay

The dashboard uses four deterministic cases from `processed_data/final_demo/demo_cases.json`.

1. Stable low-risk Stage-1 replay.
2. Persistent high-risk Stage-1 replay.
3. Independent Stage-2 botnet-family identification.
4. A contextual analyst view with both channels shown separately.

This is a **recorded dataset replay**, not a live attack simulation. Case 4 explicitly preserves the fact that the flow and PCAP evidence comes from separate, unsynchronised dataset/capture pipelines.
